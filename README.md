# Ghana Travel Explorer

A multi-page website for discovering Ghana and planning trips, built with HTML, CSS and JavaScript.

## Pages

- **Home:** menu boxes over a full-screen background
- **Did You Know?:** documentary-style stories on Ghana's independence and the castles of the Gold Coast
- **Explore:** picture tiles of destinations, with live search
- **Trip Planner:** create trips with dates, travellers, budget and places, with form validation; trips are saved in the browser and can be deleted
- **Support:** clickable questions and a contact form with validation

## What I used

- HTML: page structure, forms, links between pages
- CSS: flexbox, grid, hover effects, responsive layout
- JavaScript: the DOM, events, arrays and objects, form validation, localStorage
- Git and GitHub: version control, one commit per feature

## How to run

Download or clone the repo, then open `index.html` in a browser.
